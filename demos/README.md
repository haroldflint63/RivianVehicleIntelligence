## What to Expect

| Feature | Description |
|---|---|
| Live Telemetry | Real-time motor temp, battery %, speed, RPM gauges updated every second |
| Anomaly Alerts | Red pulsing slide-in banner when Z-Score spike is detected |
| Battery Warming | Cyan progress bar in cold-weather preconditioning mode |
| Range Prediction | Estimated miles card with temp/speed efficiency breakdown |
| LLM Status Report | Groq-powered driver summary with fade-in animation and green live dot |
| AI Support Chat | Conversational support via the Rivian AI assistant |
